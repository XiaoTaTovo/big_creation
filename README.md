# PD Insight：USB 快充协议分析仪

本仓库用于南京邮电大学大学生创新训练项目 **PD Insight：USB 快充协议分析仪** 的软硬件协同开发。

项目拟实现一款低成本、可扩展、便携式的 USB Power Delivery 协议分析设备：监听 USB Type-C CC 通信，对采集结果进行协议解析、状态归纳和图形化展示，并保留向上位机导出数据的扩展能力。

> 当前仓库处于方案细化与原型准备阶段。申请书中的技术路线属于初稿，最终器件、协议范围和验收指标应在完成可行性验证后冻结。

## 初步技术路线

- 主控候选：CH32H417；最终型号与资源分配需经原理图和原型评审确认。
- 分层设计：CC 信号前端/PHY 负责采集，软件模块负责 USB PD 报文解析。
- 任务分离：高优先级采集与时间戳处理和协议解析、界面显示分离运行。
- 展示方式：嵌入式 GUI 显示报文列表、关键字段、协商过程和错误状态。
- 扩展接口：预留 UART/USB 等数据导出方式，支持后续上位机回放与分析。

## 首个可演示目标

首个 MVP 建议只覆盖一条经过验证的主路径：

1. 对一组已知 USB PD 报文完成稳定采集或离线回放；
2. 正确解析帧类型、Header、Message ID、Data Object 数量和 CRC 结果；
3. 在屏幕上按时间顺序显示报文，并标出 Source/Sink 方向和关键协商事件；
4. 将同一组报文导出到 PC，结果与嵌入式显示一致；
5. 给出可复现的测试步骤和已知限制。

在 MVP 通过前，不把“一次性支持全部 PD 3.x/EPR/PPS、协议注入、一致性认证”等高风险目标并行展开。

## 当前待确认事项

- USB PD 目标版本和消息范围；
- 设备是纯监听器，还是还要支持电源透传、主动协商或报文注入；
- CC 前端/PHY 的具体实现与电气安全边界；
- 屏幕型号、分辨率、接口、GUI 框架和刷新率目标；
- 是否使用 RTOS，以及双核间通信方案；
- 抓包缓存大小、时间戳精度、导出接口和文件格式；
- 参考设备、示波器/逻辑分析仪条件与验收用例。

这些事项确认后，应形成版本化需求和架构决策记录，再进入大规模编码与 PCB 定版。
