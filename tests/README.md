# Tests

测试目录用于保存可重复的协议向量、主机端单元测试、硬件验证步骤和结果索引。

建议分类：

```text
tests/
├─ vectors/         小型、可授权提交的原始报文与期望结果
├─ unit/            协议解析与数据结构单元测试
├─ integration/     采集、解析、导出和 GUI 联调测试
└─ hardware/        仪器连接、设备矩阵与实测记录
```

每个测试向量应记录：

- 来源和使用权限；
- USB PD 版本与场景；
- 原始字节或符号；
- 期望的 Header、消息类型、对象和 CRC 结果；
- 是否故意包含截断、位翻转或未知字段；
- 首次加入和最后验证的提交。

不应提交包含个人信息、客户数据或来源不明的商业抓包。大体积数据使用外部制品存储，并在仓库中保存校验和与获取说明。
