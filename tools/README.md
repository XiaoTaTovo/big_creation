# Tools

PC 端辅助工具目录，优先用于降低嵌入式调试成本，而不是重复实现完整 GUI。

计划能力：

- 从串口或 USB 接收原始采集记录；
- 保存带版本号的会话文件；
- 调用与固件共享的协议解析逻辑；
- 将解析结果输出为 JSON/CSV 或可读文本；
- 回放固定测试向量；
- 比较两版固件或解析器输出；
- 生成用于报告的统计和图表。

选择语言前先确认目标：

- 需要快速编写抓取、转换和测试脚本时，可使用 Python；
- 需要复用 C/C++ 协议库时，可建立轻量命令行程序；
- 上位机图形界面不是首个里程碑的必要条件。

任何会话文件格式都应包含：格式版本、固件版本、设备信息、时间基准、原始数据和解析结果，且保持向后兼容策略。
