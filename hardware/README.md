# Hardware

硬件设计资料目录，计划保存原理图、PCB、BOM、引脚表、评审记录和打样版本说明。

## 首轮必须明确

- CH32H417 最小系统、调试口、时钟和存储资源；
- USB-C 连接方式及 Source/Sink/监听边界；
- CC1/CC2 保护、选路、偏置和输入负载；
- PD PHY 或比较器/定时器采集方案；
- VBUS 是否接入，以及过压、过流、ESD、反接和温升边界；
- 显示屏、触摸、存储和外部通信接口；
- 电源树、功耗预算、地划分和测试点；
- PCB 层数、阻抗和可制造性要求。

## 版本规则

每次打板至少记录：

- 板号与日期；
- 原理图和 PCB 源文件版本；
- BOM 版本与替代料；
- 已知问题和飞线；
- 对应固件提交；
- 上电、接口和协议验证结果。

不要只保存导出的 PDF/Gerber；在许可允许的前提下，同时保存可编辑源文件和生成说明。
